# 經典泡泡龍 (Puzzle Bobble / Bubble Shooter HTML5)

一款流暢、經典、富有街機手感的純網頁版泡泡龍遊戲。採用 HTML5 Canvas + 原生 ES6 JavaScript 開發，無任何第三方依賴，開箱即玩，支援電腦鍵鼠與手機觸控。

---

## 🌟 遊戲特色

1. **六角蜂巢網格 (Hexagonal Grid)**：
   - 經典奇偶行錯位排布（Even: 8 欄, Odd: 7 欄）。
   - 幾何切點吸附演算法，射擊入位精準不重疊。

2. **射擊與反彈系統 (Cannon & Physics)**：
   - 砲台支援滑鼠移動與手機觸控拖曳瞄準。
   - 即時計算左/右牆壁反射軌跡，虛線精準預覽反彈落點。
   - 待命泡泡預覽與即時交換功能（空白鍵 / 右鍵 / 點擊換球）。

3. **三消與懸空掉落機制 (Match-3 & Gravity Fall)**：
   - BFS 廣度優先搜尋同色相連群組，$\ge 3$ 顆即引爆消除。
   - 頂部天花板連通性檢測：被打斷支撐點的孤立泡泡群會整片脫落，具有重力下墜與底部彈跳得分動畫。

4. **天花板壓迫與死亡線 (Pressure Mechanic & Deadline)**：
   - 未命中消除時遞減壓力計數（Pressure Dots）。
   - 壓力歸零時引發天花板下壓震動與警報。
   - 泡泡堆疊觸碰到底部紅色危險警戒線時判定 Game Over。

5. **視覺與音效震撼 (Visual FX & Web Audio API)**：
   - 晶瑩水晶質感泡泡，輔以高辨識度幾何符號（紅心、方塊、梅花、星星、圓點、三角），色盲玩家亦能順暢遊玩。
   - 爆破碎屑、震屏回饋、得分浮動文字、通關彩帶粒子。
   - 純原生 Web Audio API 合成音效（發射、反彈、吸附、連續消階升調、掉落、警報、勝利喇叭），無需下載任何外掛音訊檔。

6. **豐富關卡與無盡模式**：
   - 內建 6 個精心設計的特色關卡（彩虹、愛心、城堡、旋渦等）。
   - 隨時可一鍵切換至「無盡挑戰模式」，難度隨波數自動遞增。

## 🎮 操作說明

| 操作方式 | 功能說明 |
| :--- | :--- |
| **滑鼠移動 / 手機拖曳** | 控制砲台瞄準方向（射線即時預覽） |
| **滑鼠左鍵 / 手機放開** | 發射泡泡 |
| **空白鍵 / 滑鼠右鍵 / 點擊換球** | 交換當前發射球與待命球 (Swap) |
| **鍵盤方向鍵 ← / →** | 微調瞄準角度 |
| **鍵盤方向鍵 ↑** | 發射泡泡 |
| **按鈕：無盡模式** | 在「關卡模式」與「無盡模式」之間切換 |
| **按鈕：重來** | 重新開始當前關卡 |
| **按鈕：音效** | 開啟 / 關閉遊戲音效 (Mute/Unmute) |

---

## 🚀 如何執行

直接以瀏覽器開啟 `index.html`，或者透過本地靜態伺服器啟動：

```bash
# 使用 Python 快速啟動本地伺服器
python3 -m http.server 8080
```

接著在瀏覽器打開 `http://localhost:8080` 即可暢玩！
